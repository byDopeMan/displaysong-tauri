Song Requests

Channel Points Modus

Zuschauer lösen Songs über eine Kanalpunkte-Belohnung ein. Cooldown & Zugriffsbeschränkung steuerst du direkt an der Belohnung auf Twitch.

Die Einlösung dieser Belohnung löst einen Song-Request aus.

Ohne Affiliate/Partner testen

Die Channel-Points-API von Twitch benötigt Affiliate- oder Partner-Status. Du kannst den kompletten Ablauf (Link → Spotify → Queue) hier simulieren, ohne eine echte Belohnung.

Link-Schutz aktiv

Wenn dein Chat Links blockiert, können User !sr ohne Link schreiben. Der Bot gibt dann automatisch eine 60-Sekunden Link-Erlaubnis.

Voraussetzung: Der Bot muss Moderator in deinem Channel sein.

0 = unbegrenzt

Plugin API

Noch mehr für Entwickler.

Über die Plugin-API lässt sich DisplaySong erweitern — eigene Fenster, Twitch-Events, Storage, HTTP-Requests, sogar Python-Skripte. Rechte werden pro Plugin im Manifest freigeschaltet.

1// manifest.json
2{ "id": "mein-plugin", "permissions": ["track", "twitch"] }
3
4// index.js
5async function init() {
6  const track = await api.getTrack();
7  api.onTwitchRedemption((r) => {
8    api.sendTwitchChat(`Danke ${r.user_name}!`);
9  });
10}
11return { init };
trackAktueller Song, Historie, Queue steuern
twitchFollows, Subs, Raids, Cheers, Redemptions, eigener Chat-Listener
storageEigene Daten & Settings persistent speichern
secretsTokens sicher im Windows Credential Manager
httpRequests ohne CORS-Einschränkungen
pythonPython-Skripte & Dauerprozesse ausführen
windowEigenes Fenster oder Modal, auch als echtes OS-Fenster per URL

Neu ab v4.2.1: onChatMessage, openModal, onSettingChange und Capability-Checks über api.has().

● Twitch Integration

Dein Chat wählt
die Playlist.

Viewer fordern Songs direkt im Chat an — DisplaySong konvertiert YouTube-, Apple-Music- und SoundCloud-Links automatisch zu Spotify. Ein kurzer !sr gibt per Twitch-„Permit" 60 Sekunden frei, damit der Link selbst keinen automatischen Chat-Timeout auslöst.
